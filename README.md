## Kaj delamo
V projektu obravnavamo napredne merilne sisteme, zbiranje podatko in urejamo vso pripadajočo dokumentacijo, spletno stran ter strukturo nalog prek Git-a.

## Organizacija
* **Veje (Branches):** Vsak član dela na svoji veji, koda se nato preko pull requestov združuje v `main`.
* **Projektna deska:** Uporabljamo GitHub Projects za sledenje fazam od začetka do konca.
